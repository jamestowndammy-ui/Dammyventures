# DAMMY KUSH DESIGN — Public Website Package

This is a static website built with HTML, CSS and JavaScript. It includes your brand assets and a WhatsApp enquiry form.

## Test on your computer
1. Extract this ZIP file.
2. Open the `dammy_kush_website` folder.
3. Double-click `index.html` to preview it in a browser.

## Publish a public link with Netlify Drop
1. Open https://app.netlify.com/drop
2. If prompted, sign in or create a Netlify account.
3. Extract this ZIP file on your computer first.
4. Drag the `dammy_kush_website` folder (the folder containing `index.html`) into the drop area.
5. Wait for deployment to finish. Netlify will show a public website URL that you can share.
6. Open the new URL in a private/incognito browser window to check that it is publicly visible.

The public URL is created by the hosting provider during deployment; it cannot be known before you deploy the files. A custom domain can be connected later.

## Before you share it widely
- The portfolio currently includes clearly labelled illustrative concept tiles. Replace these with your real work when ready.
- The contact form opens a prefilled WhatsApp message; it does not save submissions in a database.
- Confirm the displayed phone number, email address, and social links are correct.
- The site uses Google Fonts when available and includes fallback fonts.
- This is a static website package, not a WordPress theme.
